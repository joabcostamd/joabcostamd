# Este repositório é o perfil do GitHub. Só isso.

`joabcostamd/joabcostamd` é o repositório especial cujo `README.md` vira a página
que aparece em **github.com/joabcostamd**. Ele não guarda código.

## Não coloque nada aqui

Se você está com um arquivo na mão e não sabe onde botar, **não é aqui**:

| O que é | Onde mora |
|---|---|
| um jogo | repositório próprio, `game-<nome>` |
| um app | repositório próprio, `app-<nome>` |
| régua, ferramenta, skill, modelo de projeto | `claude-harness` |
| estudo, protótipo, pesquisa | `claude-harness` |

Este repositório já foi depósito uma vez: jogos, régua, ferramentas e perfil no mesmo
lugar. Cada jogo acabou com duas cópias, e a daqui envelheceu sem ninguém notar — o
`picross` daqui tinha 148 arquivos enquanto o `game-picross` já tinha 443.

## O que pode mudar aqui

- `README.md` — o perfil público
- `PORTFOLIO.md` — o que existe e em que estado

Texto, e só. Sem Godot, sem CI, sem script.
